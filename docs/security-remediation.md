| A-03 日志隐私 | 日志字段采用数值指标白名单；移除原始错误、JS 正文、会话 ID、媒体密钥、路径和 protobuf 十六进制转储；保留错误类型与事件名称 | Go 回归测试通过；旧日志不会自动清除，仍须作为私有数据保存 |

| A-06 Go 标准库 | 构建固定使用独立 `go1.26.9` 工具链缓存，不修改全局 Go | 重建成功；源码与二进制 `govulncheck` 扫描均为 0 条已知公告，数据库覆盖范围限制仍适用 |
| A-07 HTTP/WS 资源限制 | 正文和 WS 消息 2 MiB 上限；HTTP 读头 5 秒、读请求 15 秒、写响应 90 秒、空闲 60 秒；头上限 16 KiB；WS 写超时、ping/pong 和串行写入 | 超大正文、JSON 后附超大尾部、慢速读头、WS 超大消息及缺失参数测试通过 |

HTTP 写超时不撤回已入队的原生任务；客户端继续遵守“结果不明不自动重发”的规则。WS 客户端应响应 ping，否则连接会按 60 秒读取期限关闭。

鉴权防止不知道凭据的连接直接控制 Gadget。管理员和同一 macOS 用户下能读取凭据的进程仍不在该边界内，不能把 token 视为同用户恶意代码的隔离措施。
