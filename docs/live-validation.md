## 备份与恢复原则

切换微信版本前，必须在微信完全退出且后台服务停止的维护窗口创建应用和用户数据的离线备份。应用回滚和数据回滚是两件事；不要用旧备份直接覆盖已经产生新消息的当前数据。新版微信可能改变数据格式，项目不承诺跨版本数据无损互换。

## 重现验收

```sh
.venv/bin/python scripts/mcp_smoke.py
.venv/bin/python scripts/doctor.py
```

发送测试只允许在确认目标会话是文件传输助手后进行。发送后同时查看电脑微信和手机；如果出现未知结果，不要换新的 `request_id` 自动重发。
