# 实机验收记录

本记录描述项目在 Apple Silicon macOS 上对固定微信版本的验收范围，不包含账号、聊天数据库、截图或 token。私有原始证据不进入 Git。

## 环境

- 微信：4.1.11.53 / Build 269109
- 架构：arm64
- Frida / Gadget：17.8.0
- 测试对象：文件传输助手
- GUI 后端：默认关闭；界面检查只在用户安排的短暂空闲窗口进行

## 已完成

1. MCP stdio 握手、工具枚举和 OneBot 状态探测通过。
2. 手机发送的测试文本经签名回调进入本地 SQLite 缓存，并能由 MCP 读取。
3. 原生后台文本发送获得微信服务器回执和电脑本地消息记录编号。
4. 电脑文件传输助手显示原生后台发送的绿色聊天气泡。
5. 用户确认一条原生后台发送的测试消息同时在电脑和手机可见。
6. 持久化 `request_id` 重复调用只返回原结果，不重复发送。
7. 50 项 Python 离线测试通过；上游 OneBot Go 测试在本机固定源码上通过。

这证明了固定版本和文件传输助手文本路径的实际工作状态，不代表其他微信版本、普通联系人、群聊、媒体或完整历史导入已经验收。

## 备份与恢复原则

切换微信版本前，必须在微信完全退出且后台服务停止的维护窗口创建应用和用户数据的离线备份。应用回滚和数据回滚是两件事；不要用旧备份直接覆盖已经产生新消息的当前数据。新版微信可能改变数据格式，项目不承诺跨版本数据无损互换。

## 重现验收

```sh
.venv/bin/python scripts/mcp_smoke.py
.venv/bin/python scripts/doctor.py
```

发送测试只允许在确认目标会话是文件传输助手后进行。发送后同时查看电脑微信和手机；如果出现未知结果，不要换新的 `request_id` 自动重发。
