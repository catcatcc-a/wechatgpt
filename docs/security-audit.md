## 已核对的保护措施

- 当前工作树及已检查历史未检出真实 OneBot token、私钥或所扫描格式的服务凭据。这里的“未检出”不包括 A-01 所述个人信息。
- 当前 Gadget、OneBot 和 Webhook 仅监听 `127.0.0.1`；未发现这三个服务监听局域网或公网地址。
- 项目和服务运行目录中的数据目录为 `0700`，token 与消息 SQLite 文件为 `0600`。缓存没有应用层加密。
- 配置限制 OneBot/Webhook 使用回环地址；HTTP 客户端关闭环境代理和自动重定向。回调先校验原始正文 HMAC，再写入缓存，并限制正文大小。
- OneBot 补丁覆盖 HTTP/WS 鉴权，移除测试消息注入入口及 pprof 默认路由；启动时不打印 token。发送结果不明时不会自动重试。
- `.gitignore` 覆盖配置、token、数据库、截图、日志、证据、下载包、备份、微信副本和上游工作副本。整个项目目录仍含这些私有文件，**不可直接压缩整个目录对外分享**。

## 验证结果及限制

- Python：`pytest -q`，55 项通过；新增鉴权、重复头、非 ASCII 头、缺失 token 和安装权限回归测试。
- Go：在固定上游提交的临时干净工作树应用完整补丁，包含新增鉴权文件和测试文件；`go test -p=2 ./...` 通过。没有加载 Hook。
- 补丁与当前上游本地源码的反向应用检查通过；`git diff --check` 通过。
- Python 依赖：`pip-audit` 查询 `uv.lock` 中 36 个固定版本，无跳过包，未报告已知漏洞。查询仅提交公开包名/版本，不提交项目源码或聊天数据。
- Go 已知漏洞检查未完成：获取 `govulncheck` 时访问 Go 模块代理超时，不能据此宣称 Go 依赖无漏洞。Frida 原生库、闭源微信二进制和操作系统未完成漏洞数据库覆盖。
- 密钥扫描结合模式匹配、真实本地 token 比对和人工复核，不等同于全面渗透测试；不保证识别所有自定义凭据或个人信息。未读取完整聊天库、截图或备份内容作逐条脱敏。
- MCP 客户端拥有缓存读取和发送权限；“发送须获用户授权”是客户端指引，服务端没有逐条审批门槛。需要信任接入的客户端，并将收到的聊天内容当作不可信数据。

扫描输出和测试原始日志位于已忽略的 `artifacts/security-audit/`；它们不是公开发布材料。当前修复仅位于开发源码，旧运行日志未删除，后台服务没有重载。
